## Возможности

- Перспективная и ортографическая проекции с настройкой FOV / размера области.
- Перенос, вращение и независимое масштабирование по X, Y, Z.
- Пространственная траектория, одновременное вращение, Play / Pause / Rewind.
- Настройки скорости, радиуса, высоты и частоты вертикального движения.
- Изменение цвета через ImGui ColorEdit; выбранный RGB умножается на процедурные цвета вершин.
- Буфер глубины, контуры рёбер, управление камерой, корректное изменение размера окна.

## Сборка на macOS

Нужны Command Line Tools (Apple Clang с C++20), CMake 3.20+, Ninja и Vulkan SDK 1.4.321.0.

```sh
xcode-select --install
brew install cmake ninja
```

Установить [Vulkan SDK 1.4.321.0](https://sdk.lunarg.com/sdk/download/1.4.321.0/mac/vulkansdk-macos-1.4.321.0.zip) в `~/VulkanSDK/1.4.321.0` (путь установщика должен быть без кириллицы).

Из корня репозитория `CG` сначала перейти в каталог лабораторной:

```sh
cd lab_1
source "$HOME/VulkanSDK/1.4.321.0/setup-env.sh"
vulkaninfo --summary
cmake --preset debug
cmake --build build-debug --parallel
ctest --test-dir build-debug --output-on-failure
./scripts/run-macos.sh
```

Готовое приложение macOS находится в `build-debug/cg-lab1.app` и открывается двойным щелчком. SDK должен оставаться установленным. Также можно дважды щёлкнуть `Запустить лабораторную.command`. При первом запуске скрипт соберёт программу, если исполняемого файла ещё нет. Для пересборки после редактирования выполнить `cmake --build build-debug --parallel`.

При другом расположении SDK перед запуском задать `VULKAN_SDK` до папки `macOS` внутри SDK. macOS использует Vulkan через MoltenVK и Metal. OpenGL не используется.

Первое конфигурирование требует сети: CMake загружает закреплённые версии GLFW, vk-bootstrap, VMA и Dear ImGui. Шейдеры GLSL компилируются в SPIR-V автоматически. Пути к SPIR-V задаются при сборке; перенос каталога сборки требует повторного конфигурирования.

## Windows и Linux

Установить C++20-компилятор, CMake, Vulkan SDK и Vulkan-драйвер. Для Ninja установить Ninja; для Linux также нужны системные библиотеки разработки оконной системы GLFW.

```sh
# GCC / Clang + Ninja
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/cg-lab1
```

```powershell
# Visual Studio 2022
cmake --preset msvc-debug
cmake --build build-debug --config Debug --parallel
.\build-debug\Debug\cg-lab1.exe
```

Эти конфигурации предусмотрены, но проверка выполнения проводилась на macOS; запуск на Windows/Linux требует отдельной проверки.

## Управление

| Элемент | Действие |
|---|---|
| Perspective / Orthographic | Выбор проекции |
| Position / Rotation / Scale | Преобразования фигуры по осям |
| Enable trajectory | Наложение анимации на ручные преобразования |
| Play / Pause, пробел | Продолжить / остановить время анимации |
| Rewind | Вернуть фазу анимации к нулю |
| Speed | Скорость времени анимации |
| Trajectory parameters | Радиус, высота, частота |
| Color multiplier | RGB-множитель процедурной раскраски |
| Procedural vertex colors | Сравнение процедурной и одноцветной раскраски |
| Show edges | Показать рёбра параллелепипеда |
| Перетаскивание сцены мышью | Повернуть камеру |
| Колесо мыши над сценой | Приблизить / отдалить |
| Reset all, R | Восстановить исходные настройки |

Ввод в числовых полях можно выполнять перетаскиванием или Ctrl+щелчком. Масштаб ограничен положительными значениями 0.1–3, чтобы не вырождать геометрию. При уменьшении окна панель прокручивается.

## Математика и геометрия

Рёбра исходного параллелепипеда:

```text
a = (2.6, 0, 0)
b = (0, 1.8, 0)
c = (0.7, 0.35, 1.6)
p = ±a/2 ±b/2 ±c/2
```

8 вершин, 6 параллелограммных граней, 12 треугольников, 12 геометрических рёбер. Объём `|a · (b × c)| = 7.488`. Рёбра рисуются отдельным списком линий без диагоналей триангуляции.

Матрицы хранятся по столбцам; вершины — векторы-столбцы:

```text
M = T · Rz · Ry · Rx · S
p_clip = P · V · M · (x, y, z, 1)
```

Камера правосторонняя. Матрица проекции переводит глубину в диапазон Vulkan [0, 1] и меняет знак Y для viewport положительной высоты. Near = 0.1, far = 100. Aspect вычисляется по области сцены без панели управления.

Процедурный RGB вычисляется нормализацией локальной позиции по bounding box. В вершинном шейдере RGB умножается покомпонентно на цвет из интерфейса, затем интерполируется по треугольнику. Фрагментный шейдер добавляет простое освещение граней для чтения формы.

Траектория: `(a cos(t), b sin(k t), 0.6 a sin(t))`; углы добавочного вращения: `(23t, 45t, 11t)` градусов. Фаза растёт на `deltaTime * speed` только при активном воспроизведении. Пауза и изменение скорости не пересчитывают уже пройденную фазу.

## Структура проекта

- `source/math.hpp` — матрицы, геометрия и состояние анимации.
- `source/application.cpp` — GPU-буферы, один дескрипторный набор, pipeline, интерфейс и рисование.
- `source/main.cpp` — цикл приложения и параметры запуска.
- `source/graphics_internal.*` — каркас преподавателя с исправлениями обработки ошибок, resize, синхронизации и захватом кадров.
- `shaders/figure.vert`, `figure.frag` — вершинный и фрагментный шейдеры.
- `tests/math_tests.cpp` — проверки геометрии, проекций, преобразований, паузы и независимости анимации от FPS.
- `report/` — отчёт в DOCX и PDF.
- `screenshots/` — кадры работающей программы.

Один uniform-буфер хранит M, V, P и RGB-множитель. Он обновляется после ожидания fence, когда GPU завершил предыдущий кадр. Один набор дескрипторов фигуры привязывает этот буфер к шейдеру. Дескрипторы ImGui принадлежат самому интерфейсу и не являются реализацией задания 6.

## Проверка

На Apple M2 успешно выполнены тесты математики, валидация SPIR-V, запуск двух проекций, захват остановленной анимации и 150 кадров движения с изменением размера окна. Vulkan Validation Layers с проверкой синхронизации: 0 ошибок в финальных запусках. Скрипт `scripts/check-macos.sh` повторяет основные проверки.

## Воспроизводимая проверка

```sh
./scripts/run-macos.sh --frames 60 --capture screenshots/perspective.ppm
./scripts/run-macos.sh --frames 60 --preset 1 --capture screenshots/orthographic.ppm
./scripts/run-macos.sh --frames 60 --preset 2 --capture screenshots/animation.ppm
./scripts/run-macos.sh --frames 120 --animate --resize-test
```

Пресеты 0/1/2 открывают исходную перспективную сцену, изменённую ортографическую сцену и анимацию, остановленную на фазе 1.2. `--animate` сразу включает движение и вращение. `--capture` сохраняет реальные пиксели swapchain вместе с ImGui в PPM. Если не указано число кадров, захват завершает программу после 30 кадров. При обнаружении ошибок слоя Vulkan Validation Layers программа возвращает ненулевой код.
