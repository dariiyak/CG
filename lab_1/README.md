# Лабораторная №1

**Вариант 3 — параллелепипед.** C++20, Vulkan, GLFW, ImGui.

Выполнены основное задание и дополнительные пункты 1–5: две проекции, перемещение, поворот и масштабирование, анимация, выбор цвета и процедурная окраска вершин.

## Запуск на macOS

Нужны Command Line Tools, CMake, Ninja и Vulkan SDK 1.4.321.0 в `~/VulkanSDK/1.4.321.0`.

Из корня репозитория:

```sh
cd lab_1
./scripts/run-macos.sh
```

При первом запуске проект соберётся автоматически. Для загрузки библиотек нужен интернет.

Параметры фигуры меняются на панели слева. Мышь вращает камеру, колесо меняет расстояние. Пробел — пауза анимации, R — сброс настроек.
